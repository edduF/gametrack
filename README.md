# GameTrack

Trabalho Prático Individual — Aplicações Web — Etapa 1.

## Objetivo
Organizar uma coleção pessoal de jogos que o usuário quer jogar, está jogando ou finalizou.
A entidade principal é Jogo: nome, gênero, plataforma, ano de lançamento, status, avaliação e observações.

## Executar
Abra `index.html` em um navegador. Não é necessário instalar dependências.

## Organização
- `index.html`: identificação, navegação, pesquisa, filtros, ordenação, tabela e resumo.
- `pages/cadastro.html`: formulário de cadastro.
- `pages/detalhes.html`: detalhes completos dos três registros fictícios, com âncoras individuais.
- `assets/css/style.css`: reservado para a Etapa 2, ainda não carregado.
- `assets/js/script.js`: reservado para a Etapa 3, ainda não carregado.
- `assets/img/`: reservado para imagens futuras.

## Escopo da Etapa 1
HTML semântico com header, nav, main, section, article, aside, footer, títulos,
parágrafos, listas, tabela, links e formulários. Campos associados aos respectivos
labels, fieldsets, legendas, tipos de input e limites apropriados aos dados.
Não há imagens nesta etapa porque a interface não depende delas.

Os links de navegação e de detalhes funcionam. O botão Limpar usa o comportamento
nativo do HTML. Cadastro, pesquisa, filtros, ordenação, edição e exclusão são
controles previstos, ainda sem manipulação de dados. Todos os exemplos são fictícios.
Não há CSS aplicado nem JavaScript executado.
